Sara Chen｜一頁式個人履歷網站（五項經歷交錯版）

使用方法
1. 解壓縮 ZIP，在瀏覽器開啟 index.html，可直接離線預覽（Google 線上字體若無網路會改用系統字體）。
2. 網站設計為一頁式：頁首、導航、關於我、技能、五項經歷、照片與國慶影片、聯絡方式。
3. 五項經歷的圖片左右交錯：機器人教學（左）、志工服務（右）、國慶禮賓（左）、全民運（右）、直排輪教學（左）。
4. 五項經歷都是獨立卡片，包含角色說明、實際內容、三個學習亮點、主題標籤及佐證照片。
5. 國慶禮賓照片為白色旗袍單人照；活動紀錄區原有國慶影片與感謝狀均保留。
6. 所有圖片已轉為 WebP 並縮小；技能進度條為 CSS 製作，非圖片。

繳交方式
A. 將此 ZIP 的所有網頁檔案依老師規定繳交 i-Learning。
B. 將 index.html、style.css、image/、video/ 放在個人 GitHub 儲存庫根目錄，啟用 GitHub Pages 並繳交可直接瀏覽的連結。
兩個地方都要完成，缺任一項不計分。
