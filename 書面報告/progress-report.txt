[網站規劃]
- 採一頁式履歷，粉紫色系與五段經歷左右交錯圖文呈現。
- 區塊依序：首頁、關於我、技能專長、經歷故事、活動紀錄、聯絡我。

[素材整理]

[HTML 與 CSS]
- 使用 header、nav、main、section、article、aside、footer 語意標籤。
- 導覽列連到頁面內的 about、skills、experience、gallery、contact 錨點。
- 五項技能以 CSS 自訂進度條呈現，不使用圖檔代替。
- 經歷卡片與互動效果皆以 CSS 排版，具桌面與手機版自適應規則。
- CSS 的互動效果以註解標明。
